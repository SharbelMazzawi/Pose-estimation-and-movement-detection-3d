# DeepLabCut + Napari Tutorial

A step-by-step tutorial for using [DeepLabCut](https://www.deeplabcut.org/) and Napari for markerless pose estimation and frame annotation.  
This notebook will guide you from installation, through environment setup, to tracking body parts in your videos.

---

## 📖 Full Documentation

All instructions, explanations, and example code are provided in the notebook:  
[`01_Deeplabcut_Gui_Napari.ipynb`](01_Deeplabcut_Gui_Napari.ipynb)

---

## 📝 Sections Covered

- 🔍 What is DeepLabCut?
- ⚙️ Installation
- 🖥️ Environment Setup & Installing DeepLabCut
- 🚀 Launching DeepLabCut
- 📁 Creating a New Project
- 🔧 Defining Keypoints to Track
- (And more!)

---

## 💻 Requirements

- Python 3.8+
- DeepLabCut
- Napari
- See notebook for step-by-step package installation.

## 🏁 Quick Start

1. Clone or download this repository.
2. Open the notebook (`01_Deeplabcut_Gui_Napari.ipynb`) in Jupyter Notebook or Jupyter Lab.
3. Follow the steps inside the notebook.
